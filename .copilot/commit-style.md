# 📝 Commit Message Style Guide (with emoji)

コミットメッセージは以下の絵文字 + Conventional Commits の形式で書くこと。

## 🎯 基本形式
<type>: <emoji> <subject>

## 🏷️ Allowed types and emoji
- feat: ✨ 新機能追加
- fix: 🐛 バグ修正
- chore: 🔧 雑務
- docs: 📝 ドキュメント更新
- refactor: ♻️ リファクタリング
- style: 💄 コードスタイル修正
- test: 🧪 テスト追加
- perf: ⚡ パフォーマンス改善
- ci: 🤖 CI/CD 更新
- build: 🏗️ ビルド設定変更

## ✏️ ルール
- subject は 50 文字以内
- 語尾は「〜」で終えず、名詞止め or 簡潔な記述
- 日本語で書く
- 箇条書きの説明を追加する場合は本文に `-` で書く
